## Content rules for future additions

- Strengthen an existing relevant page before creating another similar page.
- Build pages around an actual service, actual location, and real project proof.
- Link a service page to relevant projects, and each project back to the most relevant service and market page.
- Include meaningful captions and alt text that describe visible work; do not stuff keywords into image fields.
- Use concise visible answers to real questions. An FAQ is useful only when it helps a visitor, not as filler.
