# Haven Growth Engine — measurement intake

Permanent knowledge should contain stable business facts. Upload changing performance data to each audit conversation.

## Monthly data to provide

### Google Search Console

- Performance export for the previous 28 or 90 days and the comparable prior period
- Queries, pages, clicks, impressions, CTR, and average position
- Indexing/Crawl issues, if any
- Core Web Vitals or page-experience signals, if available

### Google Business Profile

- Performance screen/export for the same period
- Calls, website clicks, direction requests, messages if used
- Search/discovery terms if available
- Review count, new reviews, and review replies
- New photos, posts, services, and category changes

### Local rank tracker, if used

- Exact keyword
- Geographic point/grid or city
- Device and search surface (organic or maps)
- Date, rank, competitor set, and ranking URL

### Lead quality

- Count of qualified calls/forms
- Service requested
- Location
- Estimated project fit/value if tracked
- Source/UTM if known

## Interpretation reminders

- Search Console average position is aggregated. It is not a promise of a local rank at one address or in Google Maps.
- Local results depend on relevance, distance, and prominence; the same search can vary by user location and device.
- Count completed, approved growth actions as leading indicators: project pages published, internal links added, photos added, review requests sent, and GBP updates completed.
