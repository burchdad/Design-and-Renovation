## Weekly Operating Cadence

Every Monday, prepare a short growth report before the client call:

1. Review Google Search Console:
   - Total clicks.
   - Total impressions.
   - CTR.
   - Average position.
   - Top queries.
   - Top pages.
   - Queries with impressions but no clicks.
   - Pages gaining impressions but ranking below page one.

2. Review Google Analytics:
   - Sessions.
   - Organic search traffic.
   - Referral traffic.
   - Mobile vs desktop traffic.
   - Inquiry form events or thank-you visits.
   - Phone-click events.
   - Highest engagement pages.

3. Review Google Business Profile:
   - Profile views.
   - Website clicks.
   - Calls.
   - Direction requests.
   - Search terms, if available.
   - Photos added.
   - Reviews received or requested.
   - Post performance.

4. Review ranking and competitor movement:
   - Search `home renovation companies in Marietta GA`.
   - Search `Marietta renovation contractor`.
   - Search `kitchen remodeling Marietta GA`.
   - Search `bathroom remodeling Marietta GA`.
   - Search `deck builder Marietta GA`.
   - Note visible competitors, directories, map pack presence, and answer-engine mentions.

5. Prepare client-facing action list:
   - What improved.
   - What stalled.
   - What needs client assets.
   - What Ghost will update this week.
   - What Micah needs to do manually.
